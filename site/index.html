Features

Everything a home server should be

Built for your own hardware, not a cloud subscription.

File sharing

Samba shares for every computer on your network, with per-user access, a Trash, and a file browser in the web page.

Storage pooling

Greyhole pools your drives into one, and keeps two or more copies of a share's files on different drives.

ZFS pools

Mirrors and RAIDZ on whole drives, with hourly and daily snapshots, roll-back, scrubs, and drive health from SMART.

Apps

Install apps from the catalog in a click. Updates copy each app's data first and roll back by themselves if they fail.

Remote access

A Cloudflare Tunnel gives a public address with no port forwarding; Tailscale a private network between your own devices.

Users

Admins, users and guests, each with the shares they may open or change, and the same password for the web page and Samba.

Security audit

Checks SSH, the firewall, Samba and updates, and fixes what it finds with a click. Every root action goes through one helper that logs it.

Setup wizard

Seven short steps on first sign-in: your password, the server's name, your drives, Greyhole and a first share.

One-click updates

Checks for updates every 6 hours and shows what's new. A failed update rolls itself back to the version that was running.
