# Security

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately with **Report a
vulnerability** on this repository's
[Security tab](https://github.com/CatDogBark/Amahi-kai/security/advisories/new), or email
catdogbark@pm.me.

Say what you found, how to make it happen, and the Amahi-kai version (Settings → System Status).
The fix ships in a release, and the advisory is published once servers can update to it.

## Supported versions

Only the latest release gets fixes; System Update installs it. The app catalog
([amahi-kai-apps](https://github.com/CatDogBark/amahi-kai-apps)) is covered here too: an app whose
manifest gives it more than it should, for example.
